The catalog is a growing collection of interactive examples — real Boboddy building blocks rendered directly on the page, not screenshots or static diagrams. Each entry shows one concept in action, alongside the fixture that produced it.

- [Pipeline Graph](/boboddy/catalog/pipeline-graph/) — a compiled pipeline's node/edge graph, rendered with the same React Flow view used by `boboddy pipelines studio`.
