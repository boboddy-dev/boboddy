This is the same graph view `boboddy pipelines studio` renders locally over a live pipeline, embedded here over static, hand-authored fixtures instead of a running server. Each fixture below is authored with `definePipeline()` — the same builder used to write a real pipeline — which compiles down to a `PipelineDefinitionSpec`. That spec is translated into `{nodes, edges}` at build time (`translateSpecToGraph`, `@boboddy/pipeline-studio-ui`'s `"."` export), then rendered client-side by the same `PipelineGraphView` component the studio uses (its `"./view"` export). Drag to pan, scroll to zoom, and use the controls in the bottom-left corner to fit or reset the view.

These examples cover node kinds worth seeing on a graph — a plain linear chain and a `choice` branch so far, with `fanOut`, `parallel`, and `loop` examples still to come.

## Linear chain

The simplest shape: a sequence of steps with no branching, ending in a terminal `succeed` node.

## Choice

A `choice` node routes to one of several targets based on its `choices[]` conditions, falling back to `default` when none match.
